# 전람회의 그림 전시관 · 음플릭스

무소륵스키 〈전람회의 그림〉을 아바타로 걸으며 감상하는 온라인 전시관이에요.

- 걸을 때는 프롬나드가, 그림 앞에 서면 그 그림의 음악이 흘러요.
- 다른 학교 친구들도 같은 시간에 들어오면 아바타로 함께 보여요. 채팅은 없고, 이름은 자동 별명(예: 씩씩한 튜바)만 써요.
- 그림 옆 벽에 감상평이 메모처럼 붙고, 누르면 감상평 전체를 볼 수 있어요. 비속어와 개인정보는 자동으로 걸러져요.

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html`, `app.js` | 전시관 화면 |
| `config.js` | **선생님이 고치는 곳**: 방명록 주소, 함께 관람 설정, 음플릭스 영상 링크 |
| `filter.js` | 화면에서 먼저 걸러내는 비속어·개인정보 목록 |
| `assets/img/01.jpg ~ 10.jpg` | 그림 파일 (없으면 기본 그림) |
| `assets/audio/00.mp3 ~ 10.mp3` | 음원 (00은 프롬나드, 없으면 기본 음악) |
| `apps-script/Code.gs` | 방명록 저장소 (구글 시트에 붙여 넣는 코드) |
| `firebase/database.rules.json` | 함께 관람용 보안 규칙 |

## 방명록 켜기 (구글 시트, 5분)

1. 구글 드라이브에서 새 스프레드시트를 만들고 이름을 `전람회의 그림 감상평`으로 바꿔요.
2. 메뉴 **확장 프로그램 → Apps Script**를 열고, 원래 있던 코드를 지운 뒤 `apps-script/Code.gs` 내용을 통째로 붙여 넣고 저장해요.
3. 위쪽 함수 목록에서 `setup`을 고르고 **실행**을 눌러요. 권한 허용 창이 뜨면 허용해요. 시트에 `감상평` 탭이 생겨요.
4. 오른쪽 위 **배포 → 새 배포 → 유형: 웹 앱**을 골라요.
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자**
5. 배포 후 나오는 **웹 앱 URL**(`.../exec`로 끝나요)을 `config.js`의 `guestbookUrl`에 넣어요.

**관리 방법**: 시트의 `상태` 칸이 `보임`인 글만 전시관에 나와요. 지우고 싶은 글은 `숨김`으로 바꾸면 1분 안에 사라져요. 자동으로 걸러진 글은 `숨김(자동)`으로 남아 있어서, 잘못 걸러진 글(예: "새끼 고양이")은 `보임`으로 바꿔 주면 돼요.

## 함께 관람 켜기 (Firebase, 10분)

1. https://console.firebase.google.com 에서 **프로젝트 추가** (이름 예: `eumflix-exhibition`, 애널리틱스는 꺼도 돼요).
2. **빌드 → Authentication → 시작하기 → 로그인 방법 → 익명** 사용 설정.
3. **빌드 → Realtime Database → 데이터베이스 만들기** (위치: 싱가포르 `asia-southeast1` 추천, **잠금 모드**로 시작).
4. Realtime Database의 **규칙** 탭에 `firebase/database.rules.json` 내용을 붙여 넣고 게시해요.
5. 프로젝트 설정(톱니바퀴) → **내 앱 → 웹 앱 추가(</>)** → 나오는 `firebaseConfig` 값을 `config.js`의 `firebase`에 넣어요.
   `databaseURL`이 빠져 있으면 Realtime Database 화면 위쪽 주소를 넣어 주세요.

무료 요금제(Spark)에서는 동시 접속 100명까지 돼요. 주고받는 건 위치와 별명 번호뿐이에요.

## 음원·그림 바꾸기

`assets/img`와 `assets/audio`에 번호대로 파일을 올리면 자동으로 바뀌어요. 그림 비율은 자유예요. 음원은 그림 앞에 서 있는 동안 반복되니 30초~1분 하이라이트를 추천해요. 음반 녹음은 따로 권리가 있으니 직접 연주했거나 사용 허락받은 음원을 써 주세요.
